# 02 — Phòng khách 16 m²

Sofa thẳng 1,8–2,2 m phù hợp hơn sofa L lớn. Giữ lối đi 800–900 mm và khoảng xem TV theo kích thước thực. Hoàn thiện nền dẫn chiếu [hạng mục chung](../08-HANG-MUC-CHUNG/README.md).

|---|---|
| [Sofa](./01-SOFA/README.md) | Sofa vải thẳng trung cấp |
| [Bàn trà](./02-BAN-TRA/README.md) | Bàn bo góc/bàn lồng nhẹ |
| [Kệ và mảng TV](./03-KE-VA-MANG-TV/README.md) | Kệ thấp; mảng phẳng tiết chế |
| [TV](./04-TV/README.md) | 50–55 inch 4K nếu khoảng xem phù hợp; mua giai đoạn sau |
