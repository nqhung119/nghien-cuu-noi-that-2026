```text
90-TAI-LIEU-DINH-KEM/
├── 01-BAO-GIA/          # PDF/XLSX báo giá; tên bắt đầu bằng ngày và nhà cung cấp
├── 02-MAU-VAT-LIEU/     # ảnh mẫu có thước/mã/lô và ánh sáng thực
├── 03-SHOP-DRAWING/     # bản phát hành, revision, người duyệt
├── 04-GIAO-HANG/        # phiếu giao, serial, ảnh bao bì/lỗi
├── 05-NGHIEM-THU/       # checklist, punch list, ảnh trước/sau sửa
└── 06-BAO-HANH/         # hóa đơn, phiếu bảo hành, liên hệ dịch vụ
```

Quy tắc tên: `YYYY-MM-DD_[OPTION-ID]_[NCC]_[LOAI]_[REV].ext`, ví dụ `2026-08-20_KIT-HOB-03_ABC_BAO-GIA_R1.pdf`. Mỗi file phải được liên kết từ sổ lựa chọn hoặc BOQ; không dùng tên `final-final2`.
