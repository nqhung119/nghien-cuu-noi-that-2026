# Dữ liệu website

`catalog.json` và `catalog.js` được sinh tự động từ `NOI-THAT-CAN-HO-MAU/`.

Không chỉnh sửa hai file sinh tự động. Hãy sửa Markdown/CSV nguồn rồi chạy `..\tools\build-data.ps1`. Bản `.json` dành cho tích hợp dữ liệu; bản `.js` cho phép website hoạt động khi mở `index.html` trực tiếp bằng `file://`.
